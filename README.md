# SVRZ Referee Coaching — App

Downloads of the **SVRZ RC** app for the referee coaches of the SVRZ.
The code lives in [Lucanepa/svrz_rc](https://github.com/Lucanepa/svrz_rc); this repository holds only the releases.

**→ [Latest version / Neueste Version](https://github.com/Lucanepa/svrz-referee-coaching/releases/latest)**

## Deutsch

Unter *Assets* die Datei für dein Gerät wählen:

| Gerät | Datei |
|---|---|
| Windows | `SVRZ.RC_<Version>_x64-setup.exe` (oder `.msi`). SmartScreen meldet evtl. «Unbekannter Herausgeber» → *Weitere Informationen* → *Trotzdem ausführen*. |
| Mac mit Apple-Chip (M1 oder neuer) | `SVRZ.RC_<Version>_aarch64.dmg` |
| Mac mit Intel-Chip | `SVRZ.RC_<Version>_x64.dmg` |
| Linux | `.AppImage` (aktualisiert sich selbst), `.deb` oder `.rpm` |
| Android | `SVRZ-RC_<Version>_android.apk` — oder über F-Droid, siehe unten |
| iPhone / iPad | keine App: https://svrz-rc.openvolley.app in Safari öffnen → Teilen → *Zum Home-Bildschirm* |

Beim ersten Start auf dem Mac: Rechtsklick auf die App → *Öffnen*.
Die Desktop-Apps aktualisieren sich selbst.

**Android über F-Droid:** in F-Droid das Repository `https://svrz-rc-fdroid.openvolley.app/repo?fingerprint=94B0129B32075340834F5FA5B87F695E0C0C198C1A5AE6DE8D8E92648FEC2881` hinzufügen (oder https://svrz-rc-fdroid.openvolley.app öffnen und den QR-Code scannen) und «SVRZ Referee Coaching» installieren — F-Droid hält die App dann aktuell. Bis Version 1.3.0 lag die App im OpenVolley-Repository (get.openvolley.app); wer sie von dort hat, fügt das neue Repository einmal hinzu, die App bleibt installiert.

## English

Pick the file for your device under *Assets*:

| Device | File |
|---|---|
| Windows | `SVRZ.RC_<version>_x64-setup.exe` (or `.msi`). SmartScreen may say "unknown publisher" → *More info* → *Run anyway*. |
| Mac with Apple chip (M1 or newer) | `SVRZ.RC_<version>_aarch64.dmg` |
| Mac with Intel chip | `SVRZ.RC_<version>_x64.dmg` |
| Linux | `.AppImage` (updates itself), `.deb` or `.rpm` |
| Android | `SVRZ-RC_<version>_android.apk` — or through F-Droid, see below |
| iPhone / iPad | no app: open https://svrz-rc.openvolley.app in Safari → Share → *Add to Home Screen* |

First start on a Mac: right-click the app → *Open*.
The desktop apps update themselves.

**Android through F-Droid:** add the repository `https://svrz-rc-fdroid.openvolley.app/repo?fingerprint=94B0129B32075340834F5FA5B87F695E0C0C198C1A5AE6DE8D8E92648FEC2881` in F-Droid (or open https://svrz-rc-fdroid.openvolley.app and scan the QR code) and install "SVRZ Referee Coaching" — F-Droid then keeps the app up to date. Up to 1.3.0 the app was in OpenVolley's repository (get.openvolley.app); if you installed it from there, add the new repository once, the app stays installed.
